# 固件从哪里获取

本项目只分发随身语音应用源码和 Windows 配套程序，**不附整机固件，也不能用 Source code ZIP 刷机**。

1. 打开 [FoloToy 口袋百宝箱玩法页面](https://ai-passport.folotoy.cn/plays/438/)。不要固定旧的 `?v=` 历史版本参数。
2. 确认页面对应同款 ESP32-C3 / 8 MB / ST7789P3 / ES8311 的 AI Passport，并且更新说明明确包含“随身语音”。若页面尚未更新，等待维护者上传，不要下载不明替代包。
3. 准备数据 USB 线，先阅读页面的刷写、备份及恢复说明，再按官网流程操作。安装会替换当前整机玩法。
4. 启动后确认应用列表有“随身语音”，完成 Wi-Fi 配置；回到 [使用教程](QUICKSTART.zh-CN.md) 设置电脑端。

已能打开该功能且版本符合教程时，不必重复刷机。此前已验证的整机版本为 `0.2.0-rc.6`；未来官网版本以其说明为准。

## 数据与刷写安全

升级前保存个人设置并做好私有备份。若官网提供 `full.bin` 合并镜像，通常从 `0x0` 写入；本项目维护者的 rc.6 合并镜像含空白 NVS，写入会覆盖 Wi-Fi、Muse 等配置区域，不能作为保配置升级。不要因为未勾“清除数据”就认为设置一定保留。

不要全片擦除，不要向未知串口写入，不要把应用分段镜像随意写到 `0x0`。需要保留数据的应用分区升级，只使用维护者明确提供并匹配分区布局的方式；这个应用源码仓库没有提供整机刷写工具或镜像。

GitHub Releases 中的 `ai-passport-voice-app-0.2.0.zip` 是电脑端/应用源码包，不是官网刷机包。
