# 0.2.0-rc.1 发布说明

**社区测试版，2026-10-02。** 将固件、精简 Windows 转发器、对应源码和从零安装教程整理在一个包中。

## 本版功能

- 正式“随身语音”页面：设备麦克风 + 一个语音快捷键，无 ASR 密钥、Agent、自动发送或清空。
- 电脑连接与语音就绪分开显示，旧版仅发心跳的电脑程序不能冒充可用音频链路。
- Windows 程序支持左右 Shift / 组合键、hold / tap、便携配置与只读诊断。
- 安装文档区分 CABLE Input / CABLE Output，给出录音、实际来源和输入法出字的逐级验收。
- 首次安装 / 应用升级烧录脚本：先校验、再备份、最后写入；避免整片擦除。
- Passport OS 整机现有功能保留，包括手机首次配网、资料/名片、收音机、小智、秒表和游戏。

## 验证与限制

之前的整机版本已通过 ESP-IDF 构建、主机测试、应用分区写后哈希及多页面实机切换。
本包额外验证结果见 `VALIDATION.md`；请区分模拟输入事件、音频回环与真正的微信识别。
**2026-10-02 补充实测：维护者确认使用刚发布的 GitHub 完整包 `0.2.0-rc.1`，
配套固件与 Windows 程序已在微信输入法中正常出字，当前识别准确。**
这一反馈替代此前“整句识别不准”和“新 EXE 尚未实机出字验收”的描述。
尚未测量字错误率或验证其他电脑、其他设备及输入法的兼容性，因此继续标为社区测试版。
本次仅更正文档和下载包内的说明，固件及 EXE 二进制保持原版；更新后的 ZIP 校验值以附件为准。

Windows x64 为本包目标环境；其他操作系统与输入法没有承诺兼容。
官方驱动、微信输入法和语音服务不随包分发。局域网语音协议未加密、未认证，只适合可信网络。

## 升级注意

固件与电脑程序一起更新。退出旧的 `relay.py`/托盘/重复转发器，再运行新版本。
删除旧程序前先保留自己的配置；本包不需要任何 ASR API Key。
旧教程中的“下键发送 Enter”“清空”“Agent 审批”不适用于本版。
