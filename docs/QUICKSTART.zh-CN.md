# 随身 AI 语音：从连接电脑到说话出字

这篇教程帮你完成一件事：**按住 AI Passport 上键，对着设备说话，松开后让文字出现在电脑输入框里。**

以 Windows 10/11 x64 + 微信输入法为例。电脑端使用本包现成程序，**不需要安装 Python，不需要填写 API Key**。
当前为 0.2.0-rc.1 测试版。2026-10-02，维护者确认使用 GitHub 完整包的配套固件与电脑程序，微信输入法能正常出字，识别准确。下面会帮助你逐步确认网络、声音和实际出字；不同电脑仍需按步骤配置。

## 先弄清楚：设备怎样和电脑配合

```text
按住设备上键，对着设备说话
          ↓ 同一局域网 Wi-Fi
电脑上的随身语音程序（start.cmd）
          ├─ 模拟你设置的语音快捷键 → 打开微信输入法语音
          └─ 把设备声音送进 VB-CABLE → 微信输入法收到声音
                                             ↓
                                  松开上键，等待文字出现在输入框
```

**固件、电脑程序、虚拟声卡、微信输入法，四者都需要。**
只刷固件或只插 USB，电脑还收不到设备的语音输入。USB 用于供电/烧录；本功能通过 Wi-Fi 传音，不需要蓝牙配对。

## 0. 固件准备：已刷好的可以跳过

同款设备可从 [一机多能－口袋百宝箱玩法页面](https://ai-passport.folotoy.cn/plays/438/?v=1061-7) 查看“如何安装”和“安装最新版”，按页面指引完成刷机。安装会替换设备当前玩法。
已经装好与电脑端配套的固件，并能进入“随身语音”的用户，直接继续下一步。

**版本要配套：本教程对应 0.2.0-rc.1 发布包。网页上的“最新版”不自动代表与本包相同；社区固件尚未同步时，以本包配套固件为准。**
需要本地烧录、备份或恢复的用户另看 [固件附录](FIRMWARE.zh-CN.md)，主教程不再展开烧录命令。

## 1. 下载后，找到正确的启动文件

1. 到 [GitHub 下载页面](https://github.com/manchunx7-bit/folo-ai-passport-voice/releases/tag/v0.2.0-rc.1) 下载完整 **`ai-passport-voice-0.2.0-rc.1.zip`**，不要只下载 `.bin` 固件，也不要选择自动生成的 `Source code`。
2. 右键压缩包，选择“全部解压”，打开解压后的文件夹。
3. 进入 **`windows`** 文件夹，你会看到：

| 文件 | 什么时候用 |
| --- | --- |
| **`start.cmd`** | 日常启动，后面配置好后双击这个 |
| `AI-Passport-Voice.exe` | 主程序，由 start.cmd 自动调用；保留在原文件夹中 |
| `diagnose.cmd` | 连不上或没声音时检查环境 |
| `voice-config.example.json` | 快捷键不同，需要修改配置时使用 |
| `install.cmd`、`.py` 文件 | 源码运行用，使用 EXE 时不需要操作 |

**本步成功标志：在解压后的 windows 文件夹里能找到 `start.cmd` 和 `.exe`。**
不要在压缩软件的预览窗口里运行；也不要只把 start.cmd 单独拖到桌面。想方便启动，可以给它创建快捷方式。

## 2. 让设备与电脑接入同一个网络

1. 没存过 Wi-Fi 的设备会进入“手机设置”。手机连接设备屏幕上显示的 `Passport-WiFi...` 热点。
2. 手机提示热点“无互联网”时保留连接；用浏览器打开 **http://192.168.4.1**。
3. 在页面里选择家中/办公室的 **2.4 GHz Wi-Fi**，输入密码完成配网。名字、签名、名片可以以后再填。
4. 电脑也接入这个路由器的网络。电脑走网线或 5 GHz Wi-Fi 均可，前提是路由器允许它与设备互通。
5. 已经联网的设备不用重新配网；需要换网络时，进入“设置 → 手机设置”。

**本步成功标志：设备完成配网、能正常进入应用；电脑也在同一局域网。**
设备热点只用于设置。不要让手机、电脑一直停在设备的配网热点上等待语音连接。
学校、公司或访客 Wi-Fi 可能隔离终端，即使网络名称相同也未必能互通；首次建议在自己家里的网络验证。

## 3. 安装 VB-CABLE，让电脑能接收设备麦克风

VB-CABLE 是一根“软件音频线”：电脑程序往一端写声音，微信输入法从另一端接收。
只需首次安装一次，之后不用每天重装。

1. 打开 [VB-Audio 官方下载页](https://vb-audio.com/Cable/)，找到 **VB-CABLE Virtual Audio Device** 的 Windows 驱动下载。
2. 下载后先完整解压驱动压缩包。
3. 在解压目录中找到适合 x64 Windows 的安装程序（通常为 `VBCABLE_Setup_x64.exe`，以实际下载包为准）。
4. 右键该程序 → **以管理员身份运行**，点击安装驱动，按安装提示完成。
5. **重启电脑**。
6. 重启后按 `Win + R`，输入 `mmsys.cpl`，回车打开声音控制面板。
7. 在“播放”页查找 **CABLE Input**；在“录制”页查找 **CABLE Output**。

| 你看到的设备 | 谁使用它 | 正确用途 |
| --- | --- | --- |
| **CABLE Input** | 随身语音电脑程序 | 把硬件麦克风声音写进去，程序默认自动选择 |
| **CABLE Output** | 微信输入法 | 作为识别用麦克风，从这里读取声音 |

**本步成功标志：两个设备都能找到，且未被禁用。输入法要选的是 CABLE Output。**
如果只有一个或都没有，先确认驱动安装成功并已重启；不要靠改文件名或反复双击 start.cmd 解决驱动问题。
保持 Windows 的默认播放设备为自己的扬声器/耳机，不要改成 CABLE Input，否则其他软件声音也可能进入这条音频线。

## 4. 配置微信输入法的麦克风与语音快捷键

### 4.1 先确认微信输入法自己能启动语音

1. 在电脑上安装并启用微信输入法。打开记事本，点击空白编辑区，让光标出现。
2. 切换到微信输入法，打开它的设置，找到语音输入相关选项。
3. 记下实际语音快捷键：**是左 Shift、右 Shift，还是其他键？是按住说话，还是点一下开始、再点一下结束？**
4. 先用电脑键盘亲自试一次：能弹出语音界面才继续。不同版本选项名称可能不同，以你的设置为准。

**本步成功标志：电脑键盘的语音快捷键能打开输入法语音界面。**
若这一步就打不开，先处理输入法设置；设备不会自动替你启用微信的语音功能。

### 4.2 把识别麦克风指向 CABLE Output

- 如果微信输入法提供麦克风选择：选择 **CABLE Output (VB-Audio Virtual Cable)**。
- 如果没有麦克风选择入口：按 `Win + R` → 输入 `mmsys.cpl` → “录制”页 → 选择 **CABLE Output** → 设为默认设备。
  然后完整退出并重新打开微信输入法，使它重新选择输入设备。该设置可能影响其他使用默认麦克风的软件；视频会议时可在会议软件中选回实体麦克风。
- Windows 11 在“设置 → 隐私和安全性 → 麦克风”；Windows 10 在“设置 → 隐私 → 麦克风”，确认允许桌面应用访问麦克风。

此时对着电脑说话不一定能识别，因为音源已改成虚拟声卡，设备还未开始传音。后面用设备测试。

### 4.3 让随身语音程序发送同一个快捷键

本程序的默认配置为 **右 Shift + 按住说话**。这只是本程序默认值，不代表微信输入法每个版本也这样设置。

| 微信输入法实际设置 | 程序应填的配置 |
| --- | --- |
| 右 Shift，按住说话 | 默认即可，不用改文件 |
| 左 Shift，按住说话 | `hotkey_key` 改为 `left-shift`，`hotkey_mode` 保持 `hold` |
| 某个键，点一下开始、再点一下结束 | `hotkey_key` 填对应键，`hotkey_mode` 改为 `tap` |

需要修改时：

1. 在 `windows` 目录复制 `voice-config.example.json` 一份，将副本命名为 **`voice-config.json`**。
2. 在文件管理器开启“文件扩展名”显示，确认不是 `voice-config.json.txt`。
3. 右键副本，用记事本打开。例如，微信设置为左 Shift 按住说话时，使用：

```json
{
  "hotkey_key": "left-shift",
  "hotkey_mode": "hold",
  "output_substr": "CABLE Input",
  "udp_port": 33333,
  "device_ip": ""
}
```

4. 保留英文引号和逗号，保存到原文件夹。其他字段先不要改。
5. 若随身语音程序已经启动，关闭它的窗口，再双击 start.cmd 让配置生效。

`hold` 表示设备按住多久，电脑键就按住多久；`tap` 表示设备按下时点击一次、松开时再点击一次。
它们都仍然使用设备的“按住上键说话”动作，区别在电脑端如何模拟输入法快捷键。

**本步成功标志：你清楚输入法实际快捷键，并且程序的键名、左右位置和触发模式完全一致。**

## 5. 启动电脑程序，连接设备

1. 双击解压目录里的 **`windows/start.cmd`**。
2. 程序会打开一个窗口，保持它开启；它就是设备与电脑之间的转发器。日常无需打开 Python 文件。
3. 首次若弹出 Windows 防火墙询问，在自己信任的专用网络允许这个程序通信。无需关闭防火墙或设置公网端口映射。
4. 在设备上进入 **“随身语音”** 页面，等待连接。
5. 查看电脑窗口的“热键”和“模式”是否与你刚才设置一致。

**正常时应该看到：**

- 电脑窗口出现 **“麦克风路由就绪”**，设备名含 `CABLE Input`。
- 设备顶部显示 **“电脑已连接”**。
- 设备主要操作提示为 **“按住上键说话”**。

如果只显示“电脑已连接”，但中央仍是“麦克风通道未就绪”，不能算跑通；先看下面的排查表。
窗口闪退时，从文件夹空白处打开终端，运行 `cmd /k start.cmd` 保留错误信息，再运行 diagnose.cmd 检查。
这是未签名的社区程序；系统拦截时先核对来源和校验值，不要关闭安全软件。

## 6. 在记事本里完成第一次语音输入

1. 打开记事本，新建空白文档，点击编辑区，确认光标正在闪烁。
2. 切换到微信输入法。
3. **按住设备上键，不要松开。**
4. 等电脑上的微信语音界面出现，再对着**设备麦克风**说：

   > 今天下午三点开会，请带上笔记本。

5. 说完松开设备上键，等待输入法完成识别。
6. 检查文字是否出现在刚才的记事本里。

**本步成功标志：按键能打开语音、说话后有文字、松开能结束，设备回到“按住上键说话”。**
设备页面传音时会显示“松开上键结束”。若窗口打开但始终没字，继续下一节检查声音来源。
本版设备不会自动发送回车、点击发送或清空文字。先在记事本验证，再用于聊天、文档等输入框。

## 7. 确认收到的真是设备声音，并排查“出字不准”

维护者已确认本包在自己的设备和电脑环境中识别准确。若你遇到错字多、漏字或不确定声音来源，可做下面的对照；已正常使用时可以直接看文末的日常启动步骤。

### 用 CABLE Output 录一小段

1. 保持电脑转发窗口和设备语音页面打开。
2. 打开 Windows“录音机/声音录制器”。若能选择麦克风，选 **CABLE Output**；若没有选择入口，确认 Windows 默认录制设备是 CABLE Output，再重新打开录音工具。
3. 点击开始录音，按住设备上键，对着设备说上面的测试句；松开后停止录音。
4. 用正常扬声器或耳机回放。录音只需保存在自己电脑里，不需要上传。

| 听到什么 | 下一步 |
| --- | --- |
| 清楚、完整、速度正常 | 声音链路基本能用；检查微信音源是否同为 CABLE Output，再与电脑实体麦克风识别同一句话作比较 |
| 全程无声 | 确认按住的是上键、设备处于传音状态；检查电脑窗口是否收到首个音频块，以及录音工具是否真的选择 CABLE Output |
| 很小、杂音重、破音或声音断续 | 先检查设备距离/遮挡、环境噪声和 Wi-Fi；不要盲目把增益拉满，过大可能破音。记录现象，按故障排查说明反馈 |
| 只有开头容易漏 | 等微信语音界面出现后再开始说话；不要按键和第一句话同时开始 |

要进一步排除电脑麦克风被误选，可临时在“录制”页禁用电脑实体麦克风，仅保留 CABLE Output 后重试，测试完恢复。
**未按设备键时没有文字，不能单独证明音源正确**，因为这时输入法也可能根本没启动。

## 8. 卡住时，先对照这里

| 当前现象 | 先检查什么 |
| --- | --- |
| 设备显示等待电脑/与电脑断开 | start.cmd 的窗口是否还开着；电脑和设备是否同一局域网；专用网络防火墙是否允许程序；是否用了隔离的访客网络 |
| 电脑已连接，麦克风通道未就绪 | 电脑是否显示“麦克风路由就绪”；VB-CABLE 安装后是否重启；是否使用本包配套固件和电脑程序 |
| 设备能传音，但微信语音不开 | 核对左右 Shift 和 hold/tap；光标是否在输入框，当前是否微信输入法；电脑键盘手动按同一快捷键能否开启 |
| 微信语音打开了，但没有字 | 微信是否选择 CABLE Output；先按第 7 节录音，再区分无声与识别服务问题 |
| 能出字，但错字很多 | 按第 7 节回放原始录音，核对 CABLE Output、说话距离、环境噪声及输入法设置 |
| 程序提示端口占用/10048 | 检查是否重复启动了多个窗口；升级用户再检查旧版程序，见详细排查文档 |

双击 **`windows/diagnose.cmd`** 可以检查声卡、配置和端口；它不录音、不模拟按键、不结束其他程序。
诊断时若自己的转发窗口还在运行，端口显示 BUSY 是正常的；关闭自己的窗口再诊断即可。
更多情况见 [故障排查](TROUBLESHOOTING.zh-CN.md)。

## 配好以后，每天只做这几步

1. 电脑双击 **start.cmd**，保持窗口开启。
2. 设备联网，打开**随身语音**，看到“按住上键说话”。
3. 点击电脑输入框，**按住上键 → 等语音界面出现 → 对设备说话 → 松开 → 核对文字**。

虚拟声卡和快捷键通常只需首次配置。不用时关闭电脑转发窗口；设备长按确定退出语音页面。
本功能限可信局域网使用，语音协议没有加密与身份认证。源码运行、固件升级等进阶操作分别见
[开发说明](DEVELOPMENT.zh-CN.md) 和 [固件附录](FIRMWARE.zh-CN.md)。
